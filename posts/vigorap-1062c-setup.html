Vigor 2135 + VigorAP 1062C 設定教學

D
Dickens
📅 2026-11-16 📖 3 分鐘閱讀 👁 256 次瀏覽

Vigor 2135 本身不具備無線功能，需透過 VigorAP 1062C 提供 Wi-Fi 訊號。本文記錄完整的 APM（中央 AP 管理）設定流程。

網路架構

Vigor 2135 作為路由器 + APM 主控端，VigorAP 1062C 作為吸頂式 AP 提供 Wi-Fi 6 訊號。

設定步驟摘要

  1. 實體連接：將 VigorAP 1062C 的 LAN/PoE 埠接至 Vigor 2135 的 LAN 口
  2. 啟用 APM：Vigor 2135 → System Maintenance → Management → 勾選 Enable AP Management
  3. 授權 AP：Central Management → AP → Status → 若出現 Unauthorized，點 Password 輸入帳密
  4. 建立 WLAN Profile：Central Management → AP → WLAN Profile → 設定 SSID、密碼、安全性
  5. 套用設定檔：Central Management → AP → Device → 勾選 Use AP Profile → Apply

後續加裝第二台 AP

APM 已啟用後，加裝第二台 1062C 更簡單：授權 + 套用相同設定檔即可，兩台 AP 會廣播相同 SSID，裝置自動漫遊。

注意事項

  • 多台 AP 記得做頻道規劃（2.4GHz 用 1/6/11）
  • 建議在 Vigor 2135 的 LAN → Bind IP to MAC 固定每台 AP 的 IP
  • Vigor 2135 最多可管理 50 台 VigorAP
