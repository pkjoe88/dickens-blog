ConfigTranslator — 伺服器設定檔註解中文化工具

D
Dickens
📅 2026-11-17 📖 6 分鐘閱讀 👁 54 次瀏覽
🈶 ConfigTranslator — 把 php.ini 與 Apache httpd.conf（含 httpd-ssl.conf、httpd-vhosts.conf）裡的英文註解自動翻譯成繁體中文（台灣口語）的桌面／命令列工具。主引擎 Google Gemini（可控制口吻），備援 Google gtx，內建翻譯快取與多金鑰輪替。

為什麼要做這個

php.ini 和 httpd.conf 的官方註解都是英文，調設定時要一直查單字。這個工具只翻譯註解文字，保留所有指令、參數名、檔名、URL、數字與程式碼片段原樣——設定檔語法完全不會被破壞，翻完照常能跑。

✨

主要功能

功能說明
雙引擎翻譯 主引擎 Google Gemini（REST API，台灣口語 prompt）；備援 Google gtx（translate.googleapis.com），Gemini 無金鑰、額度用盡或連線失敗時自動接手
批次翻譯 多段註解編號後一次送出（預設 12 段／次），在免費額度下盡量減少呼叫次數
多金鑰輪替 支援 GEMINI_API_KEYS（逗號／分號分隔）金鑰池；單把額度用盡自動標死換下一把，短暫 429/503 退避重試
智慧過濾 被註解掉的參數行（;extension=...）、段落標頭（[PHP]）、<...> 標籤行不送翻
連續註解合併 相鄰註解行先合併成一段再翻，譯文更連貫；輸出以 76 字元寬度自動折行
行尾註解支援 設定行後的行尾註解（directive = value ; comment）也會翻譯並保留原設定
編碼自動偵測 先讀 bytes 再嚴格解碼，依序嘗試 utf-8-sig、utf-8、big5、gbk、cp950、cp1252；失敗時回報不乾淨
翻譯快取 譯文落盤到 translation_cache.json，重跑直接命中快取、接續未完成的部分；統計 Gemini／gtx／快取命中／失敗段數
失敗回報 翻譯失敗的段落保留英文原文，並列出失敗行號與預覽文字
GUI 便利功能 左右窗格 50:50 均分、雙向同步捲動、右鍵選單、匯入／儲存、清空、進度列
可打包成 EXE 附 ConfigTranslator.spec，PyInstaller 打包為無主控台視窗的執行檔
📁

資料夾結構

translate/ ├── translator.py # 翻譯核心（CLI 入口 + 引擎/快取/設定檔處理） ├── gui_translator.py # Tkinter 圖形介面（translator.py 的 GUI 殼） ├── ConfigTranslator.spec # PyInstaller 打包設定 │ ├── php.ini # 原始 php.ini ├── php_zh.ini # 翻譯後的 php.ini（產生） ├── httpd.conf # 原始 Apache 設定 ├── httpd_zh.conf # 翻譯後的 httpd.conf（產生） ├── httpd-ssl.conf / httpd-vhosts.conf # SSL / vhosts 設定 ├── httpd-ssl_zh.conf / httpd-vhosts_zh.conf # 翻譯後（產生） │ ├── translation_cache.json # 翻譯快取（CLI/GUI 共用） ├── build/ # PyInstaller 中間檔（產生） └── dist/ # 打包產物 └── ConfigTranslator.exe

安裝與環境需求

  • Python 3.8 以上（開發環境為 Python 3.13）
  • 僅使用標準函式庫（tkinter、urllib、json、re、threading、textwrap 等）——不需 pip install 任何套件
  • 需要網路連線（Gemini REST API / Google gtx）
  • 使用 Gemini 主引擎需設定環境變數（擇一）：
    • GEMINI_API_KEYS：多把金鑰，逗號或分號分隔（不同 Google Cloud 專案）
    • GEMINI_API_KEY：單把金鑰（後備）
  • 可選：TRANSLATE_GEMINI_MODEL 覆寫模型名稱（預設 gemini-3.6-flash）
🔐 金鑰只透過環境變數提供，切勿寫入程式碼或提交至版本庫。
2

用法一：命令列（CLI）

cd D:\opencode\translate
python translator.py

1. 翻譯原始的 php.ini
2. 翻譯原始的 httpd.conf
請選擇要翻譯的檔案類型 (輸入 1 或 2):

接著輸入來源檔名（例如 php.ini 或 httpd.conf），程式會產生 php_zh.ini 或 httpd_zh.conf，並印出統計與失敗段落清單。

批次／自動化可直接呼叫函式：

from translator import translate_config_file
translate_config_file("php.ini", "php_zh.ini", comment_char=";")
translate_config_file("httpd.conf", "httpd_zh.conf", comment_char="#")
3

用法二：圖形介面（GUI）

python gui_translator.py
  1. 按「📂 匯入檔案」選擇 .ini / .conf / .txt，或直接貼上文字
  2. 按「🚀 開始翻譯」，左側原文、右側譯文同步顯示（雙向同步捲動）
  3. 按「💾 儲存檔案」將右側譯文存成新檔
  4. 「🧹 清空內容」可重置兩側文字
4

用法三：打包成 EXE（選用）

# 需先安裝 PyInstaller
pip install pyinstaller
cd D:\opencode\translate
pyinstaller ConfigTranslator.spec

產物位於 dist/ConfigTranslator.exe（無主控台視窗）。打包時會一併使用同目錄的 translation_cache.json（若存在）。

⚠️

注意事項（踩坑筆記）

🧠 thinkingBudget 必關：Gemini 3.x flash 是 thinking 模型，不關閉會吃光 maxOutputTokens 導致譯文截斷（程式已處理）。
💰 免費額度：Gemini 免費額度以「每專案、每模型、次數」計算；429 回覆若含小時級 retry in 會把該把金鑰標死並換下一把，不做長時間等待。
🗣 口吻限制：gtx 備援是固定書面腔，只有 Gemini 能依 prompt 輸出台灣口語。
  • 不需第三方依賴：僅標準函式庫（PyInstaller 僅打包時需要）
  • 網路需求：無網路或無金鑰時，Gemini 段落交由 gtx 處理，全部失敗則保留原文
  • 快取共用：CLI 與 GUI 共用同一個 translation_cache.json；刪除或搬移快取會重新翻譯
  • 輸出編碼：輸出一律 UTF-8；來源檔編碼自動偵測，偵測不乾淨會顯示警告
  • 不破壞設定：僅翻譯註解，指令／參數／URL／數字／程式碼片段保留原文
  • 建置產物：build/、dist/、__pycache__/ 為產生物，加入 .gitignore 勿提交
  • 版本：本工具為 V6（沿用 V5 已修的端點、編碼、快取、合併註解等修正）
