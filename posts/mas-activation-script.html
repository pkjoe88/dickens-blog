Microsoft Activation Scripts 繁體中文版

D
Dickens
📅 2026-11-17 📖 5 分鐘閱讀 👁 76 次瀏覽
🔑 Microsoft Activation Scripts (MAS) — 開源的 Windows 與 Office 啟用工具，支援 HWID、Ohook、TSforge、Online KMS 等啟用方式，並內建進階疑難排解。本篇介紹繁體中文版的使用方法與上游同步機制。GitHub：pkjoe88/Microsoft-Activation-Script-chts
1

方法 1：PowerShell 一鍵啟用（推薦）

  1. 點選開始功能表，輸入 PowerShell 並開啟
  2. 複製並貼上下方程式碼，然後按 Enter

適用於 Windows 8.1、10 和 11：

irm https://get.activated.win | iex

若上方網址被擋（ISP/DNS），改試這個（需要已更新的 Windows 10 或 11）：

iex (curl.exe -s --doh-url https://1.1.1.1/dns-query https://get.activated.win | Out-String)
  1. 在出現的選單中，輸入綠色選項對應的數字
[1] HWID
— 數位授權永久啟用 Windows（最推薦）
[2] Ohook
— 永久啟用 Office
[3] TSforge
— 啟用 Windows / Office / ESU
[4] Online KMS
— 180 天循環續期啟用
[5] 啟用狀態檢查　[6] 疑難排解　[7] 說明
⚠️ 腳本無法啟動？請改用下方的方法 2。
2

方法 2：傳統方式（Windows Vista 及之後版本）

下載腳本

版本下載說明
繁體中文版（推薦） MAS_AIO.cmd 直接下載繁中版腳本
MAS_AIO.zip 若直接下載腳本被瀏覽器或防毒軟體擋下
完整壓縮檔 .zip 包含所有獨立版啟用器與工具
原始英文版 MAS_AIO.cmd (官方) 官方英文版腳本
MAS_AIO.zip (官方) 官方英文版完整壓縮檔
  1. 執行 MAS_AIO.cmd 檔案
  2. 在出現的選單中，輸入綠色選項對應的數字
💡

提示與安全須知

🌐 部分 ISP／DNS 供應商會封鎖相關網域。可以在瀏覽器啟用 DNS-over-HTTPS (DoH) 繞過封鎖。遇到問題請造訪官方疑難排解頁面。
🛡️ 安全性：PowerShell 的 irm 命令會從指定網址下載腳本，iex 命令則會執行它。執行命令前務必確認網址正確；手動下載檔案時也請確認來源可信。請提防第三方竄改 PowerShell 命令中的網址、散布偽裝成 MAS 的惡意軟體。
🇹🇼

本繁體中文版注意事項

  • Big5 (CP950) 編碼：腳本以繁體中文 Windows 預設的 Big5 編碼儲存，不需切換 chcp 65001，徹底避開 Windows 批次解析器在 UTF-8 下的解析錯誤，並天然相容 Windows 7、8、10、11 繁體中文環境
  • 非繁中系統：非繁體中文系統（如英文版 Windows 且未將「非 Unicode 程式語言」設為繁體中文）可能顯示亂碼，請在繁體中文 Windows 環境下使用
  • 排程工作維持英文：由排程工作執行的 Activation_task.cmd 與特定內嵌腳本維持英文，以確保系統排程在任何字碼頁環境下都能穩定運行
🔄

上游同步與監控

本繁中版由 sync/ 管線自動重建：以官方英文原文 + sync/translation_map.txt 套出繁中檔案，並驗證輸出與已提交版本逐位元組一致。

用途指令
確認有沒有新版本python sync\sync_upstream.py --check-only
每日自動監控執行 sync\install_task.bat（偵測到更新才發 LINE，不會自動改檔）
同步並發佈python sync\sync_upstream.py --commit --release
📖 詳細規則與限制見專案的 sync/README.md。
