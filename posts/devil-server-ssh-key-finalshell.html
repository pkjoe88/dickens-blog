家裡 Linux 主機 devil-server 改用金鑰登入：FinalShell 設定記錄

D
Dickens
📅 2026-11-24 📖 5 分鐘閱讀 👁 1 次瀏覽

家裡有一台 Linux 主機 devil-server（Ubuntu），HiNet 固定 IP，路由器把對外 2222 port 轉到主機的 22，平常在 Windows 上用 FinalShell 連進去。今天想用密碼登入，怎麼打都不進去，一查才發現問題不在密碼，在伺服器根本不接受密碼登入。最後改成金鑰登入，一次搞定。以下是完整過程。

先查原因：sshd 只接受金鑰

在主機上看 sshd 的有效設定：

sudo sshd -T | grep -iE "passwordauthentication|pubkeyauthentication|kbdinteractiveauthentication"
pubkeyauthentication yes
passwordauthentication no
kbdinteractiveauthentication no

密碼認證是關的，鍵盤互動認證也是關的，只有公鑰認證是開的。所以密碼再怎麼正確都登不進去，這台本來就是只吃金鑰。

為什麼不直接把密碼登入打開

有兩個選擇：打開密碼登入，或改用金鑰。我選了金鑰，因為 /var/log/auth.log 裡看得到，外面的機器人天天在掃這台的 2222 port，試各種不存在的使用者名稱、對 devil 暴力猜密碼。密碼登入一開，就等於開門讓人慢慢猜；金鑰登入沒有密碼可以猜，安全得多。

第一步：在 Windows 上產生金鑰

FinalShell 吃 PEM 格式的私鑰，所以產生時要加 -m PEM，用 RSA 4096。打開 PowerShell：

ssh-keygen -m PEM -t rsa -b 4096 -f $env:USERPROFILE\.ssh\id_rsa_finalshell -C "devil-pc-finalshell"

跳出問密碼時直接按兩次 Enter（留空）。會產生兩個檔案：

  • C:\Users\DeViL\.ssh\id_rsa_finalshell：私鑰，絕對不要外流、不要貼給別人
  • C:\Users\DeViL\.ssh\id_rsa_finalshell.pub：公鑰，要放到伺服器上的那一個

用另外取檔名的方式產生，電腦上原本就有的 id_ed25519 不會被動到。

第二步：把公鑰放進伺服器

先印出公鑰內容：

type $env:USERPROFILE\.ssh\id_rsa_finalshell.pub

把印出來那整行（開頭是 ssh-rsa AAAA...）追加進伺服器上 devil 帳號的 ~/.ssh/authorized_keys，再把權限設好：

cat >> ~/.ssh/authorized_keys
chmod 600 ~/.ssh/authorized_keys

驗證一下，ssh-keygen -lf ~/.ssh/authorized_keys 應該列出三把金鑰，新的那把是 RSA 4096：

256 SHA256:sVEWviEe... opencode-from-228 (ED25519)
256 SHA256:C2WCdWxN... muse-home-linux (ED25519)
4096 SHA256:pIPQmcia9gEx0fVvF2y0CXx9BhLoBFl4tnby4nkzh7k devil-pc-finalshell (RSA)

順帶一提，.ssh 目錄權限要是 700，authorized_keys 是 600，權限不對 sshd 會直接忽略整個檔案，連不上時先檢查這個。

第三步：FinalShell 設定連線

  • 左上角資料夾圖示 → 新增 → SSH 連接 (Linux)
  • 名稱隨便填，主機填固定 IP 220.133.97.112，端口填 2222
  • 方法選「公鑰」，用戶名填 devil
  • 點「瀏覽」→「導入」→ 名稱隨便填，私鑰選 C:\Users\DeViL\.ssh\id_rsa_finalshell，私鑰密碼留空 → 確定
  • 點一下選取剛導入的金鑰（背景變淺藍）→ 確定，儲存

雙擊連線，不會再問密碼，直接進終端機。

驗證

也可以先在 PowerShell 快速測，不用開 FinalShell：

ssh -i $env:USERPROFILE\.ssh\id_rsa_finalshell -p 2222 devil@220.133.97.112

能直接進去就代表金鑰沒問題，FinalShell 那邊照上面設一定通。

「對外開著的 SSH，沒有密碼可以猜，才是最安全的。」
