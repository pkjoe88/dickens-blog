Hello, World! 我的博客開張了

📅 2026-11-16 生活 公告 📖 約 2 分鐘閱讀

歡迎來到 Dickens 的生活雜記！

這個博客的誕生，源自於一個簡單的需求：記錄生活中的點點滴滴，免得以後老了忘記去哪找以前的資料。

你可能會問：「為什麼不直接用 Notion 或 Google Docs？」

因為...我就是想有一個自己的地方。一個完全由自己掌控、可以隨時存取、不會被任何平台限制的地方。

這個博客會寫什麼？

什麼都寫！技術筆記、網路設定、生活雜記、踩坑經驗...想到什麼就寫什麼。

  • 技術教學與筆記
  • 生活中的大小事
  • 工具使用心得
  • 踩坑與除錯記錄

技術架構

這個博客使用純 HTML / CSS / JavaScript 建立，託管於 GitHub Pages。沒有複雜的建置流程，沒有框架依賴，就是簡單的靜態檔案。

如果你也想建立自己的博客，歡迎參考這個專案的原始碼。

「記錄，是為了不遺忘。」

就這樣，開始寫吧！
