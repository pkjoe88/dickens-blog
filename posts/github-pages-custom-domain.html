GitHub Pages 自訂域名設定心得

D
Dickens
📅 2026-11-16 📖 3 分鐘閱讀 👁 95 次瀏覽

記錄使用 dickens99.pp.ua 自訂域名的設定過程，包括 DNS 設定、HTTPS 憑證簽發等踩坑經驗。

設定步驟

  1. 在 GitHub Repository 的 Settings → Pages 設定 Custom domain
  2. 在 repo 根目錄建立 CNAME 檔案，內容為域名
  3. 在 DNS 代管服務設定 A 記錄指向 GitHub IP（185.199.108-111.153）
  4. 等待 DNS 傳播
  5. GitHub 自動簽發 HTTPS 憑證

踩坑紀錄

1. Proxy 狀態

如果你用 Cloudflare，初始設定時 Proxy 請設為 DNS only（灰色雲朵），等 GitHub 驗證完成後再切換為 Proxied。

2. HTTPS 憑證簽發時間

GitHub Pages 使用 Let's Encrypt，DNS 驗證完成後通常需要數分鐘到數小時才能簽發憑證。不要急。

3. .pp.ua 域名的特殊性

.pp.ua 是烏克蘭免費域名，DNS 傳播有時比一般域名慢一些，要有耐心。

最終結果

網站現在可以透過 https://dickens99.pp.ua 存取，HTTPS 憑證由 GitHub Pages 自動管理。
