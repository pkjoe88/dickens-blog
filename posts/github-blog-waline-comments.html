GitHub Pages 靜態博客加上免費留言版：Waline 實作記錄

D
Dickens
📅 2026-11-20 📖 8 分鐘閱讀 👁 1 次瀏覽

這個博客是純靜態站，放在 GitHub Pages 上，免費、穩定、不用管伺服器。但靜態站有個先天缺點：沒有後端，讀者看完文章想留句話，沒地方留。

今天把留言版接上去了。整套免費，讀者不用註冊 GitHub 帳號，填個暱稱就能留言，留言資料存在自己的資料庫，可以匯出。以下是完整做法跟踩到的坑。

先說結論：架構長這樣

留言系統拆成三件東西，全部免費：

  • 留言後端 Waline：開源留言服務，跑在 Vercel 上（Hobby 免費方案）
  • 資料庫 Neon PostgreSQL：Vercel Storage 一鍵建立，免費 1GB、100 CU-hours，個人博客用不完
  • 前端：博客原本的 js/main.js，文章頁載入時自動注入留言框

留言框長在每篇文章底部，管理後台在 /ui，第一個註冊的帳號就是管理員，可以審核、刪除留言。

為什麼選 Waline

先說被我打槍的選項：

  • Giscus：用 GitHub Discussions 當留言，缺點是讀者沒 GitHub 帳號就不能留言，直接出局。
  • Utterances：一樣要 GitHub 帳號，同上。
  • Cusdis：本來也是輕量匿名留言的首選，但 2026 年 7 月專案已停止維護，官方服務也掛了，不能用。

Waline 剛好補上這幾個缺口：訪客只填暱稱就能匿名留言，也可以登入；有管理後台、垃圾過濾、表情、圖片上傳；資料在自己的資料庫，不怕服務商哪天收掉。

第一步：部署 Waline 後端到 Vercel

用 GitHub 帳號在 Vercel 建一個免費 Hobby 帳號，從 Waline 官方範例一鍵部署。注意兩件事：

  • 官方範例在 walinejs/waline 這個儲存庫的 example 目錄，不要用 github.com/waline/waline，那個網址不存在，會 404。
  • 部署完先不要急著測留言。第一版部署是沒有資料庫的狀態，頁面會顯示「This page is unavailable」，正常。

接著在 Vercel 專案的 Storage 建立 Neon PostgreSQL 資料庫，環境變數（DATABASE_URL 等）會自動注入專案，重新部署一次讓它生效。

踩坑一：手機號只能綁一個 Vercel 帳號

Vercel 新帳號要手機驗證，一支號碼只能綁一個帳號。我第一次不小心用另一個 GitHub 帳號建了 Vercel 帳號，號碼就被那邊綁走了，正確的帳號驗證時一直說號碼已被使用。

解法是把那個誤建的 Vercel 帳號刪掉：刪除要先收 Email 驗證碼、再點信裡的確認連結，刪完號碼才會釋放。如果你的號碼也被綁住，先去檢查是不是有舊帳號佔著。

踩坑二：資料表不存在，重新部署也不會建表

這是今天最花時間的坑。資料庫接上、重新部署後，留言框看起來正常，留言列表也是空的，看起來一切正常。但一註冊管理員，伺服器就報錯：

500: relation "wl_users" does not exist

查日誌確認：資料庫連線是通的，查詢都到得了 Neon（幾十毫秒），但 wl_users、wl_comment 這些表根本不存在，而且日誌裡完全沒有建表的動作。Waline 不會在啟動或重新部署時自己建表。

解法是直接進資料庫建表。官方有現成的 PostgreSQL 建表檔，在 walinejs/waline 的 assets/waline.pgsql，裡面是 wl_comment、wl_counter、wl_users 三張表加三個序號。到 Vercel 專案 Storage 的 Query 編輯器執行，要逐條執行：整份一次貼上會報 cannot insert multiple commands into a prepared statement。建完用這句驗證三張表都在：

SELECT table_name FROM information_schema.tables
WHERE table_name IN ('wl_users','wl_comment','wl_counter');

表建好後再註冊管理員就一次成功，登入後台也正常。順帶一提：留言列表之前是空的，不是真的零留言，是根本讀不到資料——表不存在時讀留言一樣會報錯，只是前端沒顯示出來。

第二步：前端接法，只改一支 main.js

這個博客 9 篇文章頁共用同一支 js/main.js，所以留言框只要改這一支，就會出現在每篇文章下方，未來新文章也自動有，不用每篇改 HTML。

做法是在 main.js 尾巴加一段：只在文章頁（有 .post-detail-content 的頁面）執行，在 .post-nav 後面插入 #waline 容器，再從 CDN 載入 Waline 用戶端：

(function() {
  function initWaline() {
    if (!document.querySelector('.post-detail-content')) return;
    var nav = document.querySelector('.post-nav');
    if (!nav || document.getElementById('waline')) return;

    var link = document.createElement('link');
    link.rel = 'stylesheet';
    link.href = 'https://unpkg.com/@waline/client@v3/dist/waline.css';
    document.head.appendChild(link);

    var box = document.createElement('div');
    box.id = 'waline';
    box.style.marginTop = '48px';
    nav.parentNode.insertBefore(box, nav.nextSibling);

    var script = document.createElement('script');
    script.type = 'module';
    script.textContent =
      "import { init } from 'https://unpkg.com/@waline/client@v3/dist/waline.js';\n" +
      "init({\n" +
      "  el: '#waline',\n" +
      "  serverURL: 'https://waline.dickens99.pp.ua',\n" +
      "  requiredMeta: ['nick'],\n" +
      "  login: 'enable',\n" +
      "  dark: 'html[data-theme=\"dark\"]'\n" +
      "});";
    document.body.appendChild(script);
  }

  if (document.readyState === 'loading') {
    document.addEventListener('DOMContentLoaded', initWaline);
  } else {
    initWaline();
  }
})();

requiredMeta: ['nick'] 的意思是必填的只有暱稱，信箱和網址可填可不填。dark 那行是讓留言框跟著博客的深色模式切換。如果以後想在某個單獨頁面手動加留言框，不用這段 JS，直接在 HTML 裡放 <div id="waline"></div> 再加上面那段 init 就行，放哪就顯示在哪。

第三步（可選）：綁自訂域名

Vercel 免費版就能綁自訂域名。我把留言服務綁到 waline.dickens99.pp.ua，管理後台也跟著變成 https://waline.dickens99.pp.ua/ui，比一串 vercel.app 好記。

做法兩步：先在 Vercel 專案設定 → Domains 加入域名，再去 DNS（我的在 Cloudflare）加一筆 CNAME。注意 Vercel 給的目標是專屬的，我這邊是 ce759c238ab35e2a.vercel-dns-017.com.，不是通用的 cname.vercel-dns.com，照 Vercel 頁面顯示的值填。DNS 生效後，記得把 main.js 裡的 serverURL 改成新域名再推一次，留言才會走新網址。

成果與費用

  • 每篇文章底部都有留言框，訪客填暱稱就能留言，不用註冊
  • 管理後台可審核、刪除、匯出留言，資料在自己的 Neon 資料庫
  • 全部免費：Vercel Hobby、Neon 免費額度，個人博客用不完
  • 舊的 vercel.app 網址一樣能開，換域名不影響已有的留言

最後補一個後台看到的小插曲：管理頁面會跳一個「LeanCloud 即將停止對外服務」的黃色提醒。那是給用 LeanCloud 存留言的人看的，LeanCloud 2027 年 1 月要關服務，我們用的是 Neon PostgreSQL，跟它沒關係，不用遷移、不用理它。

「靜態站加留言，不用搬家，也不用花錢。」

就這樣，留言版開張了。歡迎在下面留句話試試。
